# Source and notices

Thanh Dao Pty Ltd releases this source under the MIT license in the repository root. The surface, plant and element catalogues, Bill of Quantities, material take-off, growth model, site checks and the survey, ledger, work-plan, stage and variation rules were originally developed for Auslandscape and adapted for this release: rendering code was removed, roles were renamed to contractor and client, and the project lifecycle, command line, demo and tests were added. The examples use fictional people and businesses.

This release has no runtime dependencies beyond Node.js.
