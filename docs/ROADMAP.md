# BIXSO Construction OS roadmap

**Updated 28 November 2026.** Part of the [BIXSO OS roadmap](https://github.com/THANH-DAO-PTY-LTD/.github/blob/main/ROADMAP.md). This project is the open concept and lite code for the rules in [Auslandscape](https://auslandscape.com.au).

## Now: in this repository

- Survey checks before design, and a Bill of Quantities from the drawing
- An order list with waste allowances, an indicative price range and GST
- Quotes, agreements, variations for the difference only, and client-accepted handover

## Next: help wanted

- Export the Bill of Quantities and order list as CSV ([#4](https://github.com/THANH-DAO-PTY-LTD/BIXSO-Construction-OS/issues/4))
- A simple way to draw areas instead of editing JSON
- More surfaces, rates and regional catalogues

Pick one up, or comment on the issue before you start. Items without an issue are open for an idea or a pull request.

## Questions for people who do this work

- Which take-off rule or site check would you add first?
- How do you price a variation today?

Answer in an issue using **Share an idea**, or on [r/BIXSO](https://www.reddit.com/r/BIXSO/).

## Not planned in this repository

- Contracts, payments and tax invoices; planning, building or pool-safety advice.

This is a direction, not a promise of dates. How decisions are made: [GOVERNANCE](https://github.com/THANH-DAO-PTY-LTD/.github/blob/main/GOVERNANCE.md).
