# Security policy

If you find a security issue, use [Report a vulnerability](https://github.com/THANH-DAO-PTY-LTD/BIXSO-ConstructionOS/security/advisories/new) to open a private report. Include the affected version, environment, impact and a minimal example using fictional data. Keep customer records and secrets out of the report. Use public issues for ordinary bugs and feedback.

Reports about skipping the survey, re-pricing agreed work, completing without the client or reading another project's file are in scope. This is an early project maintained on a best-effort basis.
